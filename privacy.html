Privacy Policy

Last updated: October 29, 2026

Overview

Shorts Uploader is a personal automation tool used by its owner to upload videos to their own YouTube channel. This policy explains what data the app accesses and how it is handled.

Data the app accesses

  • YouTube account access: through Google OAuth, the app gets permission to upload and manage videos on the channel of the user who signs in.
  • Video files and metadata: the video files, titles, descriptions and tags chosen for upload.
  • OAuth tokens: stored locally on the owner's own computer or server so scheduled uploads can run.

How the data is used

Data is used only to upload videos and set their details on the authorizing user's YouTube channel. Nothing else is done with it.

Sharing

The app does not sell, share, or transfer any user data to third parties. Data is sent only to Google/YouTube as needed to perform uploads.

Storage and security

OAuth tokens and credentials are kept on the owner's own machine and are never published. No user data is stored on this website.

Google API Services

Shorts Uploader uses YouTube API Services. By using it, you are also bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke the app's access at any time from your Google Account at myaccount.google.com/permissions. Revoking access stops all uploads.
